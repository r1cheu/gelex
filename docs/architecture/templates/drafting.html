§ 01 / GOAL

目标 & 数据流

从 model + method 出发，构造 prior，初始化 state——三步之间不共享秘密。

BayesPrior 位于 model 层，是贝叶斯模型的 prior contract。它聚合四个核心对象：

A · Substrate
BayesModel

数据与设计矩阵。phenotype、fixed/random、genetic effects 的承载。

B · Strategy
BayesMethod

用户选择的命名方法，把 method preset 映射为 concrete prior 构造。

C · Contract
BayesPrior

概率结构、超参数与初始化 contract。本文档的主角。

D · Trajectory
BayesState

当前推断状态。由 prior 决定的可变状态都落在这里。

数据流

auto prior = method.make_prior(model);
validate_prior_for_model(model, prior);
auto state = BayesState::init(model, prior);
禁止 / Constraints
  1. BayesPrior 不依赖 BayesMethod。
  2. 不创建 MCMC / VI kernel。
  3. 不暴露 IO schema。
  4. 不持有 phenotype、设计矩阵或采样状态。
⌐ epigraph Prior declares the shape of belief.
Kernels do the walking.
§ 02 / FILES

文件 归属

每个职责一个头文件；每个 capability 不再额外拆分。

公共接口

落在 include/gelex/model/bayes/。prior_specs.h 不依赖 BayesPrior 以避免反向拖入。capability 集中于 prior_capabilities.h。

Note · 归属原则

pure-virtual 接口无独立编译开销，新增 capability 在此追加。MCMC / VI 的 kernel registry & factory 属于 algo 层，与本模块解耦。
